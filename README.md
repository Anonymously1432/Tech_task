# Техническое задание для собеседования

Этот проект представляет собой микросервис, написанный на языке Go, который использует Docker Compose для настройки и запуска необходимых сервисов. В проекте используются следующие компоненты:

- **PostgreSQL**: Система управления базами данных.
- **golang-migrate**: Инструмент для управления миграциями базы данных.
- **Микросервис на Go**: Основной сервис, реализующий бизнес-логику.
